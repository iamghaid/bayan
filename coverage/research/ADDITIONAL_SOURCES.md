# مصادر عربية إضافية

فُحصت في 4 أكتوبر 2026. هذه مصادر للمعالجة اللغوية، وليست قواميس حركات إشارية.

## سوار — مجمع الملك سلمان العالمي للغة العربية

- المصدر: https://siwar.ksaa.gov.sa/
- خدمة المطورين: https://siwar.ksaa.gov.sa/developers
- تعرض المنصة البحث في معاجم متعددة وتتيح طلب خدمات للمطورين.
- الفائدة: مرجع عام للمعاني والمداخل العربية خارج المصطلحات الدينية.
- الحالة: مصدر موثق مرشح؛ لم ينشأ حساب أو يرسل طلب أو يحصل على API أو بيانات.

## الأنطولوجيا العربية — جامعة بيرزيت

- المصدر: https://ontology.birzeit.edu/
- البحث العلمي: https://arxiv.org/abs/2205.09664
- الفائدة: التمييز بين المعاني المتعددة، وربط المصطلح بمفهوم بدل مطابقة حروفه فقط.
- الحالة: مرجع بحثي مرشح؛ لم تُنسخ المعاجم المرتبطة ولم تُعتبر رخصها مفتوحة تلقائيًا.

## قبس — جامعة بيرزيت

- المصدر: https://sina.birzeit.edu/qabas/about
- البحث العلمي: https://arxiv.org/abs/2406.06598
- يصف المصدر نحو 58 ألف مدخلة، مع ربط 110 معاجم و12 مدونة نصية.
- الفائدة: توسيع المداخل الصرفية وتحديد الأسماء والأفعال والكلمات الوظيفية؛ لا يوفر 58 ألف إشارة.
- الرخصة المعلنة: CC-BY-ND-4.0، مع نسبة المؤلفين وعدم توزيع نسخة معدلة. لا تتبع التعريفات المحمية للمعاجم المرتبطة هذه الرخصة تلقائيًا.
- التنزيل عبر نموذج طلب في صفحة المصدر. لم يُرسل نموذج أو طلب نيابةً عن المستخدم، ولم يُستورد المعجم بعد.

## التسلسل المقترح

1. استخدام فهرس المصطلحات الحالي للمراجع وقوائم العمل.
2. طلب بيانات قبس أو وصول سوار من الجهات، مع تحديد الاستخدام التجريبي للهاكاثون.
3. إبقاء المصدر الأصلي منفصلًا وموثقًا؛ معالجة المصطلحات داخليًا قبل أي توزيع مشتق.
4. ربط المعنى بمرشح إشارة سعودية ثم مراجعة المعنى والحركة، لا التحويل الآلي عبر الجذر وحده.
