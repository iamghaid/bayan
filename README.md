# مترجم الخطبة بلغة الإشارة — أفاتار

نظام يحوّل نص خطبة الجمعة إلى إشارات يؤديها أفاتار ثلاثي الأبعاد، ويمتنع عن أي مصطلح لم يُراجَع.

## كيف يعمل
1. **المطابقة:** تطبيع النص العربي (التشكيل، الهمزات، السوابق) ثم مطابقة العبارات قبل الكلمات،
   حتى لا تُترجم «الصلاة والسلام على رسول الله» بإشارة الصلاة المفروضة.
2. **بوابة الموثوقية:** تُؤدّى الإشارة فقط إذا تحققت ثلاثة شروط في `lexicon.json`:
   `status: "verified"` (قرار المتخصص الشرعي) + ملف `sigml` موجود + `sign_reviewed: true` (مترجم أو شخص أصم أكّد الحركة).
   غير ذلك يبقى نصًا، والملتبس يُمتنع عنه.
3. **الأفاتار:** محرك [CWASA](https://vhg.cmp.uea.ac.uk/tech/jas/vhg2023/index.html) من جامعة إيست أنجليا (رخصة CC BY-SA)
   يقرأ ملفات SiGML ويؤديها.
4. **التعليق النصي** يستمر طوال الخطبة، فلا يفقد المستخدم أي جزء.

## مصدر الإشارات
قاموس لغة الإشارة العربية (3000 إشارة، HamNoSys/SiGML) — Alethary, Aliwy, Ali:
- https://zenodo.org/records/7063857
- https://zenodo.org/records/7736576

**قبل الاستخدام:** راجعوا ترخيص القاموس في صفحة Zenodo، ولهجة الإشارة المستخدمة فيه (ليست بالضرورة السعودية).

## خطوات الإعداد
```bash
# 1) نزّلوا القاموس من Zenodo وفكّوا الضغط في مجلد، مثلًا ~/arsl_dict
# 2) ابحثوا عن مصطلحاتكم فيه
python tools/find_terms.py ~/arsl_dict
python tools/find_terms.py ~/arsl_dict --copy     # ينسخ المقترح إلى sigml/
# 3) عدّلوا lexicon.json: ضعوا اسم الملف في "sigml"
# 4) شغّلوا محليًا (fetch يحتاج خادمًا، لا تفتحوا الملف مباشرة)
python -m http.server 8000     # ثم افتحوا http://localhost:8000
# 5) اضغطوا «معاينة» لكل مصطلح، وبعد تأكيد المراجع غيّروا "sign_reviewed" إلى true
```
للتأكد أن الأفاتار يعمل قبل ربط القاموس: الصقوا أي ملف SiGML في قسم «اختبار الأفاتار».

## فيديو المترجم البشري (KArSL)
المقاطع البشرية لها الأولوية على الأفاتار عند توفرها. الإشارات الدينية في KArSL أرقامها 356–456 تقريبًا، وكلها في الأرشيف `0301-0502.7z`.
```bash
# بعد فك الضغط بـ 7-Zip
python tools/pick_karsl.py "مسار/0301-0502"
```
يضع السكربت مقطعًا لكل مصطلح في `videos/NNNN.mp4`. بعد مشاهدة المقطع ومطابقته مع المصطلح، ضعوا `"video_reviewed": true`.
**لا تنشروا المقاطع على رابط عام قبل إذن د. حمزة لقمان.**

## النشر
ارفعوا المجلد كما هو إلى Netlify أو Cloudflare Pages (موقع ثابت، بلا خادم).

## حدود معروفة (تُذكر للجنة بصراحة)
- حركة الأفاتار أقل طبيعية من الإنسان، وتعبيرات الوجه أضعف.
- مدة الإشارة مقدّرة من عدد الإشارات في الملف، وليست مقاسة من الأفاتار.
- المصطلحات غير الموجودة في القاموس تبقى نصًا.
- التفريغ الصوتي غير مدمج بعد: النص مُدخل جاهزًا (الخطوة التالية: Whisper مع طوابع زمنية لكل كلمة).
